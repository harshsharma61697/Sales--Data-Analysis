Sales Data Analysis Project

Project Overview

This project analyzes sales data using Microsoft Excel to identify business trends and understand sales and profitability.

Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Excel Dashboard

Dataset

Sample Superstore Dataset containing approximately 9,995 records.

Analysis Performed

- Sales by Region
- Profit by Region
- Sales by Category
- Profit by Category
- Monthly Sales Analysis

Dashboard

Created an interactive Excel dashboard to visualize sales performance and profitability.

A Region Slicer is connected to the analysis PivotTables to filter the results.

Project Objective

To develop practical data analysis skills and present business insights through Excel reporting and visualization.
